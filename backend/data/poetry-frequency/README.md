# 诗海字衡语料和运行方式

本模块在雅集首页新增「诗海字衡」，支持唐诗与宋词范围筛选、作者精确筛选、标题关键词筛选、字频与分词词频、常用字词过滤、检索词云、次数排行、每万频率、原诗用例翻页、全文简体及语料原文切换、CSV 导出。

## 语料出处

来源：[chinese-poetry/chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)，固定版本 `b8594f81a89752241442f2ce267d6f66f96704ee`。保留原仓库 MIT 许可及版权声明，见 `LICENSE.chinese-poetry`。

使用 `全唐诗/poet.tang.<编号>.json` 和 `宋词/ci.song.<编号>.json` 共 80 个分片。不包含全宋诗、2019y 增补文件及其他文集。源文件路径与 Git blob SHA-1 记录在 `sources.json`。每个文件在导入时核验 Git blob 哈希。

原始记录 78,657 条，去除 7 条作者、标题及简体正文完全相同的重复记录、180 条无有效汉字正文或格式无效的记录，保留 **78,470 条**：唐诗 57,424 条、宋词 21,046 条。这里按语料记录计篇，组诗可能合为一条；不同题名的重收、异文及附存作品沿用源库记录，不宣称是经过校勘的独立作品总数。正文中的原有校注会参与统计。

## 统计口径

OpenCC 1.4.2 将繁体归并为简体。只统计正文，不统计标题、作者和标点。字频统计 Unicode Han 字符。词频使用 `@node-rs/jieba` 2.0.4 默认词典精确分词、HMM=false，按标点分开的连续汉字串分别分词，只保留至少二字的结果；不是滑动二元字串。古诗词存在分词歧义，可对照字频及语料原文。

次数是出现次数，涉及篇数同一记录只计一次。每万频率的分母是当前筛选范围内、过滤常用字词之前的同类统计单位数。停用词表见 `src/utils/frequencyEngine.cjs`；统计口径与来源保留在仓库文档中。词云使用当前筛选结果的前 150 项，按相对频次分配字号，经空间预算和边界避让缩放，椭圆内密集排布；排行与 CSV 保留前 30 项。云图支持放大滑动、鼠标悬停看次数、键盘选择及点词查原诗，不能据此推断诗人情绪或文学价值。

## 运行和重建

语料已随代码提供为 `corpus.json.gz`，后端首次访问时加载到独立 Worker，不需要联网下载，不需要数据库、GPU 或视觉模型。首次加载校验压缩包 SHA-256；统计结果缓存最多 20 个筛选组合，请求队列最多 12 个，30 秒超时会回收 Worker 并允许重试。压缩包约 25.9 MB，部署时不要漏掉。

在 backend 目录安装锁定依赖后，可运行 `node scripts/prepare-poetry-frequency.cjs` 重建语料。需要网络及系统 curl；必要时设置 HTTPS_PROXY。缓存下载到被 Git 忽略的 `backend/.cache/poetry-frequency`。重建依据已提交的 sources.json，不跟随远端 master 变化。运行时不执行分词，分词结果已经预存。

接口：`GET /api/poetry-frequency/meta`、`/stats`、`/contexts`、`/poems/:id`。筛选参数为 corpus=tang/song/空、author、title、mode=char/word、stop=0/1；上下文额外接受 term 与 page，每页 10 条。数据只读，输入校验、有限队列和 Worker 将计算与主服务隔离。

- `/home`：首页入口、白话雅译新插画，移除译文旁「闲」字印章。
- `/poetry-frequency`：统计二级页面，可通过地址参数保留筛选。
- `/poetry-frequency/poem/:id`：全文三级页面，展示原文件来源。
- 全局 `DesktopStageWings` 组件和专用样式已删除，登录、注册及其他路由均不再显示左右展示栏。
