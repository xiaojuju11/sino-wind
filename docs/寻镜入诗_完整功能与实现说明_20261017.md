# 云山竹简「寻镜入诗」模块完整功能与实现说明

文档日期：2026年10月17日

所属项目：云山竹简 · 华风雅集

关联栏目：首页「寻镜入诗」、书斋「诗境画阁」

说明范围：本文以当前本地代码和已完成验证为准，区分已实现功能与后续扩展。

## 一、模块定位

「寻镜入诗」将用户拍摄或上传的风景照片，与古诗中的意象建立可以点击、可以解释的联系。用户先选择眼前景物，再寻找相宜的原诗，最终将照片与诗句组合成自己的诗境作品。

完整链路：

```text
首页摄景寻诗
    ↓
拍照 / 相册 / 山水画示例
    ↓
照片压缩与检查
    ↓
语义分割识别景物 + 单目相对深度估计
    ↓
点选景物 / 更正名称 / 手动补选
    ↓
按意象匹配原诗，选择相宜诗句
    ↓
展开我的诗境
    ├─ 原景展示
    ├─ 循诗观景：点击诗词意象，突出画面区域
    └─ 山水层次：根据估计深度呈现轻微视差
    ↓
收入诗境画阁 / 导出高清长图 / 携景向先贤请教
```

## 二、页面和入口

| 页面 | 入口或路径 | 主要作用 |
|---|---|---|
| 首页模块卡片 | 首页古诗词赏析下方 | 展示山水插画，点击「摄景寻诗」进入模块 |
| 寻镜入诗编辑页 | `/scene-poetry` | 上传、识景、调整意象、选择原诗 |
| 诗境草稿展示页 | `/scene-poetry/view/draft` | 展示当前照片与诗句，交互观景、收藏、导出 |
| 诗境画阁 | 书斋新增栏目，`/mine/scenes` | 展示当前账号在此浏览器保存的作品 |
| 已藏作品详情 | `/scene-poetry/view/:id` | 再次展开作品，查看、导出、携景论诗 |

首页「摄景寻诗」按钮复用古诗词赏析「展卷细读」的同一套样式，包括圆角、边框、字体、箭头和配色。诗境画阁复用书斋二级页面的动态山水背景与返回栏体系。

## 三、完整功能说明

### 3.1 拍照与相册选图

- 「拍下眼前」通过带有 `capture='environment'` 的文件输入提供后置摄像头拍照入口，具体表现取决于设备与浏览器。
- 「从相册选取」支持 JPG、PNG、WebP。
- 前端限制原始文件不超过 12MB、图片不超过 2400 万像素。
- 将照片等比例缩小至最长边不超过 1280 像素，再编码为 JPEG，减少上传与存储开销。
- 「换一幅」可替换当前照片；新照片使用新的作品编号。
- 提供内置山水画示例，可以直接体验链路。示例是生成的插画，同样交给模型现场分析，没有预置识别结果。

### 3.2 真实景物识别

后端使用 **SegFormer-B1 / ADE20K** 预训练模型进行语义分割，采用 q8 量化权重。

它的输出是“哪些像素属于什么景物”，而非只有一个照片标题或几个固定框。例如一张湖边照片，可能识别出树木、水面、天空、建筑等区域。

当前接入的类别映射包括：

| 模型类别示例 | 页面意象类别 |
|---|---|
| tree、plant、grass | 树木、草木、芳草 |
| water、river、lake、sea | 水面、江河、湖水、海面，统一归入水意象 |
| mountain、hill | 山峦、山丘 |
| sky | 天空 |
| flower、rock | 花、山石 |
| bridge、boat、ship | 桥、舟船 |
| building、house、tower | 建筑、屋舍、楼塔 |
| path、road、waterfall | 小径、道路、瀑布 |

没有映射到诗境用途的类别不会强行展示。占比过小的区域会被过滤，以减少杂乱轮廓。

### 3.3 景物轮廓与点选

- 后端返回景物区域的像素掩膜，并附带区域编号、标签、来源、面积比例和归一化边界框。
- 前端用 Canvas 检查掩膜邻近像素，找到区域边缘，绘制金色轮廓。
- 已选区域显示淡色覆盖层；用户可以点击画面切换区域选择，也可以通过下方标签选择。
- 交互掩膜使用最长边约 384 像素的网格，降低返回数据量和前端绘制开销。
- 掩膜采用 RLE 游程编码，连续像素记录为“起点、长度”，前端再解码使用。

语义分割按类别组织区域，同类的多棵树可能合并为一块区域，目前不提供逐棵树的实例编号。识景输入最长边提高到 512 像素，交互输出提高到 384 像素，避免原先提前缩至 256 像素损失细节；这不是更换或重新训练模型。

### 3.4 人工修正与补选

- 每个区域都有名称选择框，可将模型候选更正为合适意象。
- 「补选意象」允许选择标签，在图片上拖出矩形区域。
- 可以取消补选，也可以重新运行识景。
- 数据内部保留模型、手动圈选和人工更正的来源，页面不再展示这些来源标记。
- 柳、竹、荷、月、星辰等细意象可以由用户确认，不因检测到普通树木、水面或天空就自动认定存在。

人工补选当前为矩形区域，尚未实现手绘任意形状或交互式精细抠图。

### 3.5 按意象匹配原诗

当前收录 **29 条精选古诗节选**。每条记录包括作品编号、标题、作者、朝代、诗句、意象锚点和简要解读。

匹配流程：

1. 读取用户选中的景物标签与面积，同类区域合并计算，避免重复计分。
2. 将标签与每条诗的意象锚点进行比较。
3. 检查必要景物条件，计算区域面积、意象权重与覆盖比例。
4. 排序后展示最多 6 组候选诗句。

当前排序公式：

```text
意象显著度 = 语义权重 × √选中区域面积比例
支持度 = 诗句命中意象的显著度之和 ÷ 全部所选意象的显著度之和
分数 = 支持度 × 30 + 覆盖比例 × 8 + 命中的不同意象数量
只有满足该诗必要景物条件，才参与排序。
```

例如《过故人庄》的“绿树村边合，青山郭外斜”对应树木、山峦。现在还需要选中与村落对应的建筑区域，才推荐这组诗句，避免给野外群山配上村落诗。

- 没有选中意象时，不展示虚构的匹配结果。
- 用户可以在候选中更换所选诗句。
- 配诗使用必要意象约束：没有雨景不推荐《约客》，没有舟和雪不推荐对应舟雪诗句；页面保留景物点选，不展示技术性候选说明。
- 每条作品提供作者、标题与维基文库原文检索入口；该入口是检索链接，并非已逐一核验的固定版本原文页。

这部分是精选语料与可解释规则索引，尚未使用向量检索或专门训练的诗词推荐模型。

### 3.6 展开诗境与循诗观景

进入「我的诗境」后，展示照片、原诗节选、作者、朝代、标题和「入诗」印章。

提供以下查看方式：

| 方式 | 交互效果 |
|---|---|
| 原景 | 展示照片与题诗 |
| 循诗观景 | 点击带描线的诗词意象，突出照片中的对应区域 |
| 山水层次 | 有深度结果时，轻移指尖或鼠标观察细微远近视差 |

例如点击“树”，突出树木区域；点击“山”，突出山峦区域。只有与选中区域建立联系的词语可以进行这种联动。

「此景与此诗」区域给出简要解读和意象关联。静态图片无法确认的声音、时节等内容不会作为额外识别结论。

### 3.7 单目深度与山水层次

后端使用 **Depth Anything V2 Small** 预训练模型，采用 q8 量化权重，估计照片的相对深度。

前端实现方式：

1. 将原照片和相对深度图作为两张纹理交给 WebGL。
2. 根据鼠标或指尖相对位置计算偏移。
3. 根据各像素估计深度，计算不同幅度的位移。
4. 使用平滑插值缓和位移变化。

雪、柳、竹等细分类别不在当前分割模型的直接识别范围内，需要用户确认或补选。

该效果为单张照片的轻微 2.5D 视差。它不能给出真实米制距离，也没有生成被遮挡部分的完整几何。

- 用户启用减少动态效果时，减少相应运动。
- 深度模型失败时仍可选景配诗。
- WebGL 不可用时回退为原图。
- 页面退出时清理绘制任务和 WebGL 资源。

### 3.8 入诗与诗境画阁

「入诗」是实际收藏按钮：

```text
入诗 → 保存中 → 已藏 → 再次点击打开诗境画阁
```

- 保存成功后，下方「收入诗境画阁」按钮同步显示已收藏状态。
- 画阁按照保存更新时间展示作品。
- 卡片显示照片、诗句、作者、保存内容关联的创建日期，并可进入详情。
- 刷新页面后可以继续回看。
- 「再寻一境」返回编辑页。
- 「移出」会先显示确认框，确认后删除此浏览器的该份藏卷。
- 空收藏显示空状态和前往寻镜入诗的入口，不以示例冒充用户收藏。

### 3.9 高清长图导出

- 使用原生 Canvas 2D 绘制，不使用 html2canvas。
- 组合照片、古诗节选、作者与标题、项目名称、金色边框和朱红印章。
- 按设计宽度 600 像素的 2 倍输出，成图宽度为 1200 像素，高度随照片比例变化。
- 照片保持比例置于画面中，不直接拉伸填满。
- 导出为 PNG，文件名包含诗题。

当前导出内容为静态照片与题诗，不导出 WebGL 动态、视频或交互掩膜图层。

### 3.10 携景论诗

用户可以选择「请教李白」或「请教苏轼」。

系统将所选景物名称、作者、诗题和原诗节选填入对应对话输入框，由用户确认后自行发送。草稿会提示区分实景描述与文学联想。

当前只传递文字草稿，尚未将照片或视觉特征传给聊天模型，因此不能声称先贤已直接看过图片。

## 四、数据保存与处理方式

### 4.1 保存位置

收藏使用浏览器 IndexedDB，数据库名为 `yunshan-scene-poetry-v1`。

按项目现有 `scholarScope()` 结果分开查询游客和各账号的记录。作品主要包含：

| 数据 | 用途 |
|---|---|
| 作品编号、创建时间、更新时间 | 识别作品与排序 |
| 压缩照片 | 原景展示、长图导出 |
| 景物标签、掩膜、来源 | 点选、纠正、诗句联动 |
| 深度图及尺寸 | 山水层次展示 |
| 选中区域编号、诗歌编号 | 恢复作品选择 |
| 账号作用域、收藏状态 | 本机归档查询 |

本机作用域区分不是服务端权限控制。清除网站数据、换浏览器、换设备后，当前作品不会自动从云端恢复。尚未实现跨设备收藏同步、游客收藏归并和公开分享链接。

### 4.2 图片流向

照片由前端发送到本项目后端做推理；当前识景接口以内存方式处理，没有主动把照片写入服务器文件。收藏由前端保存在本机浏览器。

识景时使用本地模型文件，禁用运行时远程模型获取；不需要把照片发送给 Hugging Face 托管推理服务。

## 五、后端接口与运行机制

### 5.1 模型状态

```http
GET /api/scene/status
```

返回分割模型文件是否就绪、当前是否繁忙、模型名称与深度模型文件是否存在。文件存在检查不等同于完整推理自检。

### 5.2 照片分析

```http
POST /api/scene/analyze
Content-Type: application/json
```

请求主体：

```json
{ "image": "data:image/jpeg;base64,..." }
```

成功结果主要字段：

```text
code: 1
data:
  width / height       掩膜和深度网格尺寸
  regions[]            区域编号、标签、来源、RLE 掩膜、面积、边界等
  depth                相对深度数组，可能为空
  depthNotice          深度处理提示
  model / depthModel   实际使用的模型名称
```

异常响应：

| 状态码 | 含义 |
|---|---|
| 400 | 图片格式、内容或像素不符合要求 |
| 429 | 正在处理另一张图片 |
| 503 | 模型未准备、推理中断或超时 |

当前后端在工作线程内运行模型，首次使用时加载，后续请求复用。一次处理一个分析请求，超过 90 秒终止；用户中止请求也会结束对应推理工作线程。页面错误提示会保留当前照片，便于重试或手动选景。

## 七、运行与部署准备

当前验证环境使用 Node.js 22。新增主要依赖：

- `@huggingface/transformers`：3.8.1。
- `sharp`：0.34.5。

模型放在 `backend/models/scene`，已由 Git 忽略，不随代码推送。队友首次拉取或新服务器部署时需要单独准备。

```powershell
# 从仓库根目录进入后端
cd backend
npm ci
powershell -File scripts/prepare-scene-models.ps1

# 如需代理，在准备模型时追加：
# -Proxy http://127.0.0.1:7897

node src/index.js
```

另开终端启动前端：

```powershell
cd frontend
npm ci
npm run dev
```

本地前端通常为 `http://127.0.0.1:5173`，后端为 3000，前端通过 Vite 代理访问 `/api`。正式部署需要配置对应的 API 转发、请求体大小与超时。

模型固定来源：

| 用途 | 模型仓库 | 固定 revision |
|---|---|---|
| 语义分割 | Xenova/segformer-b1-finetuned-ade-512-512 | `6308717ce1fc0f39dd847e3b2e98edebc4ace4a0` |
| 相对深度 | onnx-community/depth-anything-v2-small | `4472b7362082ad9968fee890ca0f1e5aca36b93d` |

默认 B1 与深度权重合计约 40MB，尚不包含 Node 运行时和依赖体积。

- 色彩沿用项目宣纸底色、墨色、古金与朱砂色。

## 十、当前边界和可扩展方向

| 当前实现边界 | 可扩展方向 |
|---|---|
| ADE20K 固定类别，细意象需人工确认 | 接入更细类别或开放词汇分割，并增加标注评测 |
| 同类景物可能合并 | 引入实例分割，独立选择多棵树、多艘船 |
| 384 像素长边交互掩膜，细枝可能粗糙 | 提高网格或边缘细化，配合移动端性能测试 |
| 29 条精选节选、规则匹配 | 扩充核验语料，加入向量检索与结果重排 |
| 轻微 2.5D 视差 | 在合适设备上探索更完整的分层呈现 |
| IndexedDB 本机收藏 | 增加服务端收藏、跨设备同步与游客归并 |
| 一次一个推理请求 | 增加队列、并发调度、限流与部署监控 |
| 携景论诗只传文字 | 经明确设计后，将照片或视觉特征接入多模态对话 |

## 十一、模型来源与答辩表述

两个视觉模型采用公开预训练权重，当前没有自行训练或微调。团队完成的是模型接入、景物与文学意象映射、交互联动、轻量视差、收藏与导出，以及与原有业务的衔接。

建议介绍为：

> 我们将语义分割、单目深度估计与古诗意象检索结合，让用户通过自己的照片选景寻诗。诗句中的意象能够反向定位到照片区域，并形成可交互、可收藏、可导出的诗境作品。

模型使用需保留真实来源。SegFormer 上游许可包含非商业研究/评估用途限制，商业发布前需确认授权或更换模型；Depth Anything V2 Small 的所用模型页标注 Apache-2.0。权重未纳入 Git。

## 十二、人工验收流程

1. 打开首页，在古诗词赏析下方点击「摄景寻诗」。
2. 选择一张自己的风景照片，等待候选景物显示。
3. 点击图片或标签，取消不需要的区域；尝试更正一个标签。
4. 选择一种意象，在图中拖动补选区域。
5. 从候选诗句中选择一组，点击「展开我的诗境」。
6. 点击诗句中带描线的字，确认对应景物突出显示。
7. 切换「山水层次」，轻移鼠标或指尖查看视差。
8. 点击「入诗」，确认印章变成「已藏」，下方按钮同步更新。
9. 再次点击「已藏」，进入诗境画阁；刷新后确认作品仍在。
10. 展开作品，导出高清长图，检查照片比例、诗句和作者。
11. 点击请教李白或苏轼，确认内容仅填入输入框，由自己决定是否发送。
