## 五、 录制操作与工程执行备忘录

1. **录制工具建议**：OBS Studio（1080P / 60fps，码率 12000 Kbps，开启 NVENC 硬件编码）。
2. **分辨率配置**：
   * 手机端单列特写镜头：使用 Chrome DevTools 手机模拟器（390×844，DPR=2）；
   * 宏观文博大屏展卷态镜头：使用 1920×1080 全屏视窗（自动激活左翼天象罗盘与右翼先贤修持看板）。
3. **音画同步要点**：
   * 00:30 处“摘录入卷”操作必须与 `playInkDropSound` 音效落点严丝合缝；
   * 01:25 处飞花令点击“格律透视”必须特写展开推导动画与 `playChimeSound` 编钟音。
4. **配音语速建议**：解说词全长约 480 字，平均语速 160 字/分钟，给评委留出充分的视觉消化与审美余白。
