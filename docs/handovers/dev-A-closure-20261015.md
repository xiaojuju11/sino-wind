## 生态接口契约

### GET /api/deepseek/scholar/summary

沿用现有 Authorization 鉴权，返回 `{code:1,data:{nickname,avatar,appraise_count,artifact_count,debate_count,poem_count,yayan_count}}`。不返回手机号、密码、凭证。现有 auth/info 字段未修改。

### POST /api/deepseek/scholar/sync

```json
{"turns":[{"id":"完整UUID","sageId":"libai","question":"原问题","answer":"完整原回答","at":1792022400000}]}
```

每批最多100轮；问题≤2000字、回答≤4000字，时间为毫秒且不得超出当前时刻一分钟。成功 `{code:1,data:{accepted:["UUID"],pointsAwarded:0}}`。参数错误400；同 UUID 原文冲突或临时保存失败409（已确认的 accepted 位于响应顶层）；数据库不可用503。本机原稿不因错误删除，重试幂等。此接口只归档个人材料，不证明模型真实调用，也不增发修持竞技积分。
