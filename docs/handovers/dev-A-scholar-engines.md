## 1. SSE与逐字动效

- 新增 `POST /api/deepseek/chat/stream`；原`/chat`及其他JSON接口兼容保留。
- DeepSeek请求真实使用`stream:true`，通过UTF-8 SSE发送`meta`、`delta`、`replace`、`done`或`error`事件。
- Koa流体、30秒上限、8秒心跳、写背压、客户端断开取消上游、计时器/监听器清理。
- 前端POST Fetch流式读取（可携带Bearer鉴权），支持跨网络包UTF-8及CRLF边界；不以完整JSON回复模拟真实模型流。
- 水墨字符队列每24ms逐步显示，支持停止、切换先贤取消、减少动态效果偏好和中文输入法Enter防误发送；无模型或生成前失败有明确离线标识。
- 保留既有人设清洗：留出40字符检查窗口，触发后替换为标记的本地回应。此启发式规则不等同于任意提示下的绝对保证。
- 实际DeepSeek一次公开测试：source=`deepseek`、首段1484ms、总计2403ms、131字符、done正常。测试未携带用户私人内容，不打印凭证。网络/模型首段延迟仍存在，不承诺零等待。

## 3. 原生Canvas文牒

- 原生Canvas 2D手写渲染，不用html2canvas、DOM截图、SVG图片或外链字体。
- 文字由右向左分列、列内由上到下；标点定位、动态高度、列组居中和溢出保护。
- 程序化宣纸细纹、双边框，印章外框与四字笔画均使用三次贝塞尔路径；每局编号决定边缘和倾角变化。字形为本项目原创几何仿篆装饰，非古文字学字形认证。
- 固定逻辑宽600、输出宽1200，即2x；已从实际按钮下载并查看1200×2160 PNG。内容含姓名、先贤、令字、韵部、对局诗句、结果、实得积分、编号及上海时区日期。
- 胜局为通关文牒，负/和局为研习文牒；附研习纪念说明，不冒充学历或资格证书。
