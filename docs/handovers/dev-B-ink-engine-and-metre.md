**真算法要点（对齐"拒绝硬编码"）**
1. **节气由天文算出**：儒略世纪数 → 几何平黄经 + 中心差（3 摄动项）+ 章动/光行差 → 太阳视黄经；
   节气 = 黄经每 15° 等分点。**零日期对照表**。
   （算法细节：节气边界须取**最近** 15° 倍数而非向下取整，否则黄经 359.56° 会误判为惊蛰。）
2. **物理三力可分别验证**：重力（`vy=g·t`、位移 `½gt²`）、空气阻尼（`v·e^{−k·dt}`）、
   湍流风向（多频正弦叠加 + 每粒子相位差）。半隐式欧拉 + 固定子步长 → **帧率无关**
   （30fps 与 120fps 位移差 < 0.6px）。
3. **布朗运动是真随机游走**：高斯增量（Box–Muller）+ `√dt` 缩放。
   实测 MSD 吻合离散朗之万精确解（比值 2.165 vs 理论 2.140，弹道段应为 4）。
4. **涟漪按 √t 扩散**（扩散过程），统一水位线触发（非每滴各自随机高度）。
5. **手势交互**：划动 → 水墨笔触 + 墨滴粒子（自身受重力下坠）+ 按轨迹生成排斥点驱动粒子躲避
   （法向冲量 + 三次方衰减，越近越弹；快速划动插值补点不断线）。

**实测证据（390×844，CDP）**

  交互监听直接挂在题头元素上，**不新增任何覆盖层**）；

| `frontend/src/pages/PoemPage.jsx` | +80 | 接入「格律雅析」区块 |

**真算法要点**
1. **平仄判定三级优先**：平水韵字表 → 补充入声/仄声表 → 普通话四声回退，
   并标记 `confidence`（`rhyme-book`/`modern`/`polyphone`）。界面按可信度区分着色，
   `△` 表示两套表都未覆盖 —— **不猜测、不伪装**。
   **入声是关键**：白/月/雪/不/一/十/落/独/客 等普通话读平声、平水韵为仄，只能靠字表判对。
2. **句式识别**：首二字定「起」、末字定「收」，匹配四种基本句式（五言/七言各一套）。
3. **三项核验**：替（句内 2/4/6 位交替）、对（联内出对句相反）、粘（联间相同）。
4. **押韵校验**：一韵到底、只押平声；首句借邻韵识别为**「孤雁出群格」**（info）、
   出韵（error）、撞韵（warn）分级报出。
5. **五维评分全部由诗作自身特征推导**（不硬编码）：
   - 格律 ← 替/对/粘合规率
   - 音律 ← 韵脚一致率 + 平仄交替密度 + 句长整齐度
   - 意境 ← 意象词密度 + 六门类覆盖 + 字面变化度
   - 风骨 ← 刚健/阔大语汇数 + 虚词克制度
   - 用典 ← 典故标记词 + 人物/地名实体（可枚举的显式证据）
   每维附 `contributions` 明细（权重 + 是否达标），界面可展开「为什么是这个分」。
6. **雷达图纯数学**：`θᵢ = −π/2 + 2πi/n`（自正上方顺时针）、`rᵢ = R·score/100`；
   网格环/轴线/标签锚点（按 `cos` 决定对齐）全部三角函数算出；面积用鞋带公式自检。
7. **弹性形变是真弹簧**：`x'' = −k(x−target) − c·x'`（欠阻尼），固定 1/120 子步长；
   每维一根独立弹簧，切换诗词时**过冲再回稳**，而非线性 tween。

**实测证据（390×844，CDP）**
- 雷达图 5 顶点全在 SVG 视口内（`allInsideViewBox = true`）；
- 切换诗词时**过渡期 10/10 帧顶点逐帧变化**（弹性形变生效，非线性跳变）；
- 单字判定浮层实测显示「平声 · 平水韵【十三覃】· 依据：平水韵字表」；
- 光/暗两种主题下 `overflowX = false`、Console 0 报错。
