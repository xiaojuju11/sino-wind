# 刘霞 · 参考稿视觉精修交接

日期：2026-10-14。分支：`feat/visual-reference-polish`，基线：`713180d`。

本轮根据用户上传的前七张浅色参考及第八张夜景稿，调整雅集、知音信札、迎请抽屉、先贤对席、诗词鉴赏/检索、书斋与诗笺的视觉层。保留主线新增的藏牒阁、修持文阶、物溯宝鉴、格律声谱及五维雷达，未为贴图删减功能。

## 修改说明

- 新增隔离的 `referencePolish.less`：宣纸、描金双线、回纹角花、朱砂印、CSS 卷轴轴杆、正文尺寸下限、窄屏和夜色配色；`ReferenceCorners` 仅作装饰，不充当按钮图标。
- 复用 `InkWashBackground` 到上述页面；用户随后明确允许安全完善队友引擎，因此新增 `inkLandscape.js`，以种子几何生成远近山峦、皴笔松影、竹叶、岸亭、孤舟和日月，去掉旧底图采样与图片兜底。首页保留粒子与水墨交互，粒子显示区域通过遮罩避让正文；动态竹枝仅留首页。
- 山水几何按尺寸/主题缓存到离屏 Canvas，动画阶段仅复用缓存，加入飞鹤、薄雾、月晕和水纹；保留既有 30fps 氛围调度、周期静歇、DPR 上限 1.5。输入（含 select）、后台与减少动态效果继续暂停，不承诺所有设备固定帧率。
- 李白对席新增透明人物立绘；人物图只作装饰，不作整页背景或按钮。
- 后续用户明确“李白是示例，其他诗人聊天背景可以自行生成”，因此聊天页另接入七套专属场景（含竹林群聊），以用户最新指示覆盖此处原先仅限人物的约束。场景贯穿聊天区；隐藏重复的 Hero 立绘，气泡头像使用场景中相同的人物（CSS 取景）。其余页面纯 Canvas 山水不变。
- 新图位于 `frontend/public/assets/scholar-scenes/`，单图 190192–279146 bytes，仅当前场景加载；失败和未知自定诗人回退程序化背景，不借用李白的场景。夜间独立调色，叠加层只绘制动态雾气/飞鹤/月晕/水纹，不重复绘制通用山峦。完整生图提示词见该目录 README。
- 日夜纹样采用已安装 `antd-mobile-icons` 的 CompassOutline/StarOutline（当前安装库没有日/月专用图标）；其余操作图标继续使用内置 iconfont/官方库。雷达 SVG 属于数据图形，保留数学绘制。
- 迎请抽屉改朝代选择框并开放生涯纪略编辑；原快捷先贤、头像选择、考释与提交逻辑保留。信札新增按姓名、头衔、实际摘要筛选。
- 旧玻璃质感和四页旧夜色强制规则排除 `.reference-polish`，避免覆盖新宣纸层；未更改主题令牌或主题状态逻辑。
- 修复基线 Home 使用 `InkWashBackground` 却缺少 import 的问题。
- 未改公共路由、接口契约、端口、依赖、凭证或旧 stash；未提交或推送。
