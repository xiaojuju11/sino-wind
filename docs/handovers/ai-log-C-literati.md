## 三、 人工筛选、修改、重构与二次创作过程（⚠️ 竞赛重点核验项）

### 1. 人工筛选与内容把关：
* **视觉美学筛选**：AI 原生生成的插画容易带有现代商业仙侠感或日韩古风偏向。本人严格比对两宋院体画与明清文人画的笔墨意趣，淘汰了色彩浮夸、衣冠制式不合礼制的候选图，最终甄选出李白、苏轼、王阳明、李清照四大文宗的高洁意境立绘。
* **业务与交互逻辑筛选**：舍弃了 AI 建议的复杂现代个人中心“积分等级升级”、“九宫格卡片”等偏离文化氛围的交互形态，自主确定了以“文人书斋”为主轴、以“宣纸竹简卡片”为容器、“四列修持数据看板”与“双折叠清规列表”为骨干的纯粹文人体验。

### 2. 视觉素材的人工二次加工（高强度人工工作量）：
* **图像精修与抠图重绘**：使用专业图形工具对 AI 原生生成的先贤立绘与卷轴素材进行去噪、去杂色、人物轮廓微调及边缘羽化处理，修正手指与服饰细节瑕疵。
* **宣纸肌理与渐变融合层手工制作**：独创“宣纸微融画卷”技法，手工在卷轴素材左侧绘制具有水墨宣纸质感的半透明羽化遮罩（`linear-gradient` 宣纸底色过渡），使右侧高清画面能够自然隐没于左侧米白题字区中，彻底消除生硬边界。
  > **勘误（2026-10-17）**：本条原文将右侧画面写作「高清真迹」，易被误读为古画扫描件。
  > 结合本表第 28 行（Midjourney v6 生成）与第 40 行（对 AI 原生生成素材加工）可知，
  > 该画面实为 **AI 生成插画**。申报与答辩请统一表述为「AI 生成 + 人工精修」，原文「真迹」措辞作废。
* **资源工程化裁剪与优化**：将全部素材按高清视网膜屏标准规范化裁剪并压缩为标准化 Web 资产，归类存入 `public/assets/guancang/` 与 `public/assets/shuzhai/` 目录。

### 3. 代码与系统的手工重构与编写（核心技术成果）：
* **模块化组件手写实现**：AI 提供的仅为离散参考代码片段。本人独立重构编写了 `AIPage.jsx`、`MinePage.jsx` 与 `AccountSetting.jsx` 完整的 React 19 组件生命周期、状态机及事件响应系统。
* **高阶 Less 样式工程手写**：手动编写了 `aiPage.less`（290+ 行）、`minePage.less`（340+ 行）及 `accountSetting.less`。构建了基于 `@color-seal: #9E2A2B`（朱砂红）与 `@color-gold: #C5A059`（赤金）的视觉层次，手写了先贤卡片 active 态金色流光微动效、卡片点击阻尼反馈及圆弧印章。
* **定制 Iconfont 字体图标体系整合与统一**：针对多图标库源冲突及色彩不一问题，在 `index.html` 引入专属国风矢量图标库（`font_5241957_dms3u40idy.css`），并在 Less 中手写全局样式穿透覆盖规则，强制将所有列表图标锁定为统一朱砂色（`#9E2A2B`）与 24px 基座对齐，彻底解决排版错乱。
* **多端自适应架构设计**：独立重写 `rem.js` 动态计算引擎，加入了 `320px ~ 540px` 视口区间夹紧算法；在 `app.less` 与 `layout.less` 中手动构建了最大宽度 `480px` 居中防畸变画幅与长卷背景铺底，兼顾真机小屏与 PC 宽屏展示。
* **状态存储与安全交互**：集成 Ant Design Mobile `ActionSheet` 典雅抽屉交互，手写 `localStorage` Token 清理与鉴权状态注销逻辑，健全 Mock 优雅降级数据兜底机制。
