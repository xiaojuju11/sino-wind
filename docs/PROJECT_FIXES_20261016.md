# 2026-10-16 项目问题修复记录

本次针对 `fix/ancient-cities-location` 分支的项目检查结果修复，保留现有页面样式、API 路径与端口，不提交或推送分支。

## 安全

- 上传：文件指纹仅接受前端既有格式及规范的 MD5/SHA256；分片索引、分片总数必须是有限且有界的整数。读写、合并和递归清理均校验固定目录边界。
- 合并：先写唯一临时文件，流成功关闭后才发布最终文件；错误保留原分片供重试，同一指纹的重复合并返回冲突，避免部分文件被误判秒传。
- 账户：头像和昵称接口分别限定单一字段，模型层拒绝主键和密码哈希。改密通过专用模型执行，仍必须验证旧密码。
- JWT：移除公开默认密钥，缺失、过短或旧默认配置时拒绝启动。`.env.example` 和 README 补充配置要求。本机不安全配置已替换为随机密钥，仅写入 Git 忽略的 `.env.local`；旧本机登录需重新登录。生产环境仍需独立配置密钥。

## 业务

- 定位：IP 失败返回无结果，继续 GPS/IP/默认城市链路，避免将杭州兜底误标为 IP 成功。使旧缓存失效；用户手动选城会取消自动定位，旧响应不覆盖选择；存储不可写不影响成功定位。
- 飞花令：指定韵部时先贤与玩家同样严格校验，题库无合规句则按原规则判玩家胜；自由换韵保留原行为，页面说明同步。
- 游客文牒：正常结算和恢复已完成对局均写入本机归档；本机存储失败提示导出/重试，不把服务端已确认结算误报为失败。
- 诗笺：移除预置假收藏，区分加载、失败重试、游客及真实空收藏；删除仅在服务端确认后更新界面，失败保留原条目，账户变更时阻止旧操作。
- 雅言：书斋读取首页已有的本机摘录，显示原文、署名、释义、日期和来源，明确本机存储范围；存储失败不再提示收录成功。
- 自定义先贤：对话携带受类型/长度限制的人物资料，服务端构造角色规则；预设先贤人设不能被覆盖，刷新恢复本机人物，降级不借用李白身份。
- 请求：Axios 全局超时设置到正确的 `defaults.timeout`，既有长任务可继续显式覆盖。
