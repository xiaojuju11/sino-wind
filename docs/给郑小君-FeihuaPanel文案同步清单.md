## 先看规则变了吗（一句话）

| | 改版前 | 改版后（现行） |
| :--- | :--- | :--- |
| **玩家侧** | 本轮首个有效句把整局韵部**锁死**，此后异韵即判负 | 每句韵脚只需**能被平水韵收录**即通过，**可自由换韵** |
| **先贤侧** | 必须与玩家同韵，否则无句可应 | **优先同韵**；同韵句耗尽时放宽为任意韵脚，**不判负** |
| **开局选韵** | 首句定韵，或开局指定 | 开局指定 ⇒ 本局**严格同韵**（保留）；不指定 ⇒ 自由换韵 |

改动缘由：原规则会「用正确名句反被判负」——
令字=月 时提交「举头望明月」会把韵锁成`入声六月`，再提交「床前明月光」
（光属`七阳`）直接判负。且 210 个「令字×韵部」组合中仅 1 个可用句数达 8 句，
锁定后几乎无句可续。详见 `docs/飞花令押韵方案讨论.md`。

## 需要修改的 4 处

### ① 第 70 行 —— 顶部规则说明（**必改**）

原文：
```jsx
<p>三十息应令，同韵续句，双方不可重复。先贤从公开经典题库应答；胜得三分、和局一分，败局不计分。未登录可体验，积分不入书斋。</p>
```

问题：「同韵续句」已不再强制，会误导玩家以为必须押同一韵。

建议改为：
```jsx
<p>三十息应令，句末须为平水韵所收，可自由换韵；指定韵部则本局同韵。双方不可重复。先贤从公开经典题库应答；胜得三分、和局一分，败局不计分。未登录可体验，积分不入书斋。</p>
```

### ② 第 74 行 —— 韵部下拉的第一个选项（**必改**）

原文：
```jsx
<label>平水韵<select value={rhyme} onChange={e => setRhyme(e.target.value)}><option value=''>首句定韵</option>{(rules?.availableRhymes?.[keyword] || []).map(r => <option key={r}>{r}</option>)}</select></label>
```

问题：`value=''` 现在表示「不锁韵、可自由换韵」，不再是「首句定韵」。

建议把选项文案改为：
```jsx
<option value=''>不限（自由换韵）</option>
```
> 备选文案：「不限韵」「自由换韵」—— 你按视觉长度取舍。

### ③ 第 76 行 —— 对局中的韵部显示（**必改**）

原文：
```jsx
<div className='feihua-round'><strong>令：{game.keyword} · {game.rhyme || '首句定韵'}</strong>...
```

问题：`game.rhyme` 在自由换韵模式下**始终为空**（后端不再回写），所以会永远显示
「首句定韵」，而实际规则已不是这样。

两种改法，**推荐 A**：

**A（推荐）** —— 显示上一句（先贤句）的实际韵脚：
```jsx
<strong>令：{game.keyword} · {game.rhyme || (game.turns?.length ? `上句韵：${(game.turns.at(-1).line || '').slice(-1)}` : '不限韵')}</strong>
```

**B（最省事）** —— 只改兜底文案：
```jsx
<strong>令：{game.keyword} · {game.rhyme || '不限韵'}</strong>
```

> ✅ 方案 A 的代码**已实测**（2026-10-15，对该接口真实请求）：开局后提交「举头望明月」，
> `game.rhyme === ""`（自由换韵模式确为空串），`game.turns.at(-1).line` 为
> `"举杯邀明月"`，`.slice(-1)` 取到 `"月"`；`Array.prototype.at` 可用。

### ④ 第 92 行 —— 「规则与经典题库」折叠区（**必改**）

原文：
```jsx
<p>首个有效句确定韵部，此后句末须同部。多音字不猜读音，请开局指定韵部。不含令字、重句或错韵即负；未收录句不判负但计时继续。六轮完整唱和判和局；先贤无可应之句则雅士胜。离开页面不暂停，未结算不发积分。每局十五分钟后过期。</p>
```

问题：这段整句都在描述已废弃的规则（「首个有效句确定韵部，此后句末须同部」、
「错韵即负」）。

建议改为：
```jsx
<p>每句句末一字须为平水韵所收，可自由换韵；若开局指定韵部，则本局须同韵。多音字不猜读音。不含令字、重句或指定韵部下的异韵句即负；未收录句不判负但计时继续。先贤优先以同韵句应答，无可应之句则雅士胜。六轮完整唱和判和局；离开页面不暂停，未结算不发积分。每局十五分钟后过期。</p>
```

变更点逐条对照：
| 原文 | 改为 |
| :--- | :--- |
| 首个有效句确定韵部，此后句末须同部 | 每句句末一字须为平水韵所收，可自由换韵；若开局指定韵部，则本局须同韵 |
| 多音字不猜读音，**请开局指定韵部** | 多音字不猜读音（不再要求必须指定韵部） |
| 不含令字、重句或**错韵**即负 | 不含令字、重句或**指定韵部下的异韵句**即负 |
| 先贤无可应之句则雅士胜 | 先贤**优先以同韵句应答**，无可应之句则雅士胜 |

## 建议新增的 1 处（可选，但体验提升明显）

### ⑤ 韵部下拉里显示「该令字在该韵部有多少句可用」

**可复用后端已有字段**：`rules.availableRhymes[keyword]` 返回的是
「该令字实际有诗句的韵部」列表 —— 但**不含句数**。

如果你愿意，可以在改后端时给这个字段带上句数（**属我的目录，你说一声我就加**），
前端把选项渲染成：

```jsx
{(rules?.availableRhymes?.[keyword] || []).map(r =>
  <option key={r}>{r}{rules?.rhymeCounts?.[keyword]?.[r] ? `（${rules.rhymeCounts[keyword][r]} 句）` : ''}</option>
)}
```

**为什么值得做**：实测数据显示——若选到只有 1~2 句的韵部，**开局即无句可续**
（花 25 个韵部中 14 个只有 1 句；春 33 个韵部中 26 个只有 1 句）。
现在玩家选韵时完全看不到这个信息，等于在踩坑。

> 若你暂不做，也没问题 —— 押韵规则改版后**默认就是「不限韵」**，不选就不会踩坑。
