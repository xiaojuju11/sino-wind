## 一、 从参考图提炼的视觉 DNA（五个必备元素）

> 缺任何一个，就会退回队长所说的「太平、太丑」。规范原文见 `DESIGN.md` §2.5。

| # | 元素 | 具体做法 | 参考图证据 |
| :---: | :--- | :--- | :--- |
| 1 | **全屏水墨背景层** | 整屏铺满水墨山水（竹、远山、飞鸟、红日/淡月、亭台、渔舟、梅花），米黄宣纸调；卡片浮在画面上。**不能只有纯色底** | 四张全部，尤其图 1、图 4 |

## 二、 另外几处容易漏掉的细节

- **竹简与木轴**：每日诗签是**真竹简**（竖条纹理）+ 两端黑酸枝木轴 + 左侧竖排朱砂标签；图 3 的三张功能卡左右两端也是木轴。
- **标题两侧的云纹分隔线**：形如「—— 读千年风雅 与君共此山河 ——」，细线 + 云纹小节点，不要裸分割线。
- **字重比现有实现更重**：板块标题是**粗宋/行楷**（600~700），朱砂或水墨浓黑；正文 13~14px；标签 11~12px。
- **底栏**：米黄纸底 + `1px` 泥金顶线；图标为**器物线性图标**（亭台 / 鼎 / 书卷），激活态为朱砂图标 + 文字 + 短下划线。
- **输入框**：描金细边框 + 圆角，**不填充底色**（图 1）；左侧配线性图标。
- **顶部**：标题居中，右侧常有朱砂小印；页面顶部不做 AppBar 式工具栏。

## 三、 与现行 `DESIGN.md` 的关系

`DESIGN.md` §2.5 已把上表固化为强制规范，并**明确作废**早前「一个区域至多一处装饰元素」「泥金只做描边不做填充」的极简读法——那套读法产出的稿子正是队长判为「太丑」的原因。

判断口径也一并改了：**五元素同时出现即为达标**；只有纯色底 + 发丝描边、无插图无印章的稿子，判「未达标」。
