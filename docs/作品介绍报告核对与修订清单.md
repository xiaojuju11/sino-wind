## 八、模型名核对（2026-10-21 更新，重要）

> 此前核对曾提出“DeepSeek 没有 deepseek-flash，应写 deepseek-chat”，该结论已作废。官方文档（`https://api-docs.deepseek.com/`，2026-10-21 抓取）当前只列两个模型名：`deepseek-flash`（由 DeepSeek-V4.1-Flash-1017 提供服务）与 `deepseek-v4-pro`。

| 项 | 核对结果 |
| :-- | :-- |
| 报告写 `deepseek-flash` | ✅ 与官方文档一致，无需修改 |
| 代码原本写死 `deepseek-chat`（5 处对话 + 1 处流式） | ⚠️ 已改为 `deepseek-flash`，统一收口到 `backend/src/utils/deepseekModel.js`，可用环境变量 `DEEPSEEK_MODEL` 覆盖 |
| `deepseek-chat` 是否还能调 | ✅ 实测仍可用，但响应头 `model` 返回的是 `deepseek-flash`（旧名已成为别名，随时可能下线） |
| `deepseek-flash` 默认行为 | ⚠️ 默认开启思考：同一句雅译 6.9 秒、899 个 reasoning token；`max_tokens=300` 时思考会把预算吃光、正文为空 |
| 关闭思考后的表现 | ✅ `thinking: {type:'disabled'}`：雅译 1.28 秒返回合格 JSON，角色对话 1.65 秒返回正常文本；已统一设置，需要时用 `DEEPSEEK_THINKING=enabled` 打开 |
