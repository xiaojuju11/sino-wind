# 移动应用参赛完善实施计划

目标：落实已确认的参赛评估建议，使核心诗境体验易发现、结果来源明确、工程与展示材料可核验。

1. 修正展示事实：移除硬编码的成功率与耗时；标记内置器物案例，不赋予预设评分，不将案例收入个人识物成果。
2. 收敛体验：将现有寻镜入诗入口置于首页首个内容区；保留其他栏目；增加本机藏卷说明与系统分享的下载回退。
3. 文化依据：为精选诗句增加固定原文页及核验元数据，保留无法确认的语境边界；展示可解释的意象匹配理由；格律未知字不再被概括为通过。
4. 可交付性：将识景规则测试接入常规测试，提供模型部署检查与实机测试记录流程；不将模拟接口视作真机/真实模型验收。
5. 材料：修正 CMIT/4C 混写和超出实现的技术陈述，提供原创贡献清单、用户试用任务与原始记录模板。

验证：针对案例来源与收藏限制、格律未知字、诗词来源数据和分享回退增加行为测试；运行前后端测试、ESLint、构建；浏览器核对移动尺寸入口、案例标识、诗境来源和失败恢复。真实参与者试用与 iPhone/Android 实机验收单独记为待测。

边界：保留品牌、视觉体系与现有栏目，不重写原生 App，不宣称训练基础模型或已取得用户效果；不自动发布线上版本。
