# 云山竹简国风语音设计

## 目标

为 DeepSeek 生成的识别讲解、诗词赏析和先贤对话提供稳定的微软 Edge TTS 国风音色，并让手机浏览器可以通过用户点击播放。浏览器本地语音合成仅作为服务不可用时的降级方案。

## 方案

后端提供一个文本转语音接口，接收待朗读文本和受限的音色标识，调用 Edge TTS 生成 MP3，并按文本、音色和语速生成稳定缓存键。静态音频由后端公开目录提供，前端使用原生 `Audio` 播放。接口失败、网络不可用或设备无法播放时，前端回退到 `speechSynthesis`。

音色映射为：

- 苏轼、李白、杜甫、辛弃疾等男性先贤：`zh-CN-YunxiNeural`
- 文史讲解和中性旁白：`zh-CN-YunjianNeural`
- 李清照及女性先贤：`zh-CN-XiaoxiaoNeural`

接口只接受白名单音色和长度受限文本，不接受任意远程 URL。缓存目录使用后端已有静态资源托管能力，避免重复生成同一段音频。

## 前端接入

抽取共享语音工具，负责请求音频、播放、停止、状态和降级。识别结果页、诗词页和先贤对话页复用该工具；播放动作必须由用户点击触发，以兼容 iOS、安卓和微信内置浏览器的自动播放限制。页面卸载、切换路由或隐藏时停止播放。

## 错误处理

后端生成超时或上游失败时返回明确的 503；前端不阻塞正文展示，直接降级为浏览器语音或显示可继续阅读的状态提示。缓存写入失败不影响接口返回本次音频。

## 验证

- 后端测试覆盖音色白名单、文本长度限制、缓存键稳定性和失败响应。
- 前端构建验证三处页面可以编译。
- 在桌面浏览器和手机尺寸浏览器中验证点击播放、停止、切页停止及无后端时的降级。
