## 一、 系统架构与技术全景图

### 1.1 总体架构设计

本项目采用前后端解耦架构，客户端面向移动端轻量体验（锁定 390px 视口等比 rem 适配），服务端基于轻量高效的 Node.js Koa 框架，通过标准化 RESTful 协议与大模型 API（DeepSeek LLM、多模态视觉模型）进行交互。

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       《云山竹简 · 华风雅集》系统架构全景图                    │
└─────────────────────────────────────────────────────────────────────────────┘
                                  │
         ┌────────────────────────┴────────────────────────┐
         ▼                                                 ▼
【前端表现层 Client (React 19 + Vite)】         【后端服务层 Server (Koa 2)】
 ├─ 路由系统 (React Router v7)                    ├─ 中间件栈 (Koa-Router, CORS, Body)
 │   ├─ /home (雅集首页)                          ├─ 控制器层 (Controllers)
 │   ├─ /letters (知音信札)                       │   ├─ deepseekController.js
 │   ├─ /chat/:id (沉浸对话)                      │   │   ├─ deepseekChat (多先贤对话)
 │   ├─ /poem (古诗大卷轴)                        │   │   ├─ translateYayan (白话雅译)
 │   ├─ /recognition (物溯古今)                   │   │   └─ soulScholar (一键考释赋魂)
 │   └─ /mine (墨隐书斋)                          │   ├─ poemController.js
 ├─ 全局上下文与设计系统                          │   └─ cozeController.js (视觉多模态)
 │   ├─ ThemeContext (晓色晨宣 ☀️ / 月下墨境 🌙) ├─ 第三方大模型服务
 │   ├─ CSS Variables (--gf-bg-paper, --gf-seal)  │   ├─ DeepSeek LLM (OpenAI-compatible)
 │   └─ Web Audio API (免版权古琴五声音阶合成器)  │   └─ Coze / 通义千问多模态
 └─ 网络层 (Axios 封装 + 离线优雅降级兜底)        └─ 本地数据兜底与持久化存储
```

## 🎨 队长特别禁令：图标统一使用 iconfont（严禁 AI 直接做图）

> ### ⚠️ 队长特别强调（全员必读执行）
> 1. **严禁让 AI 直接生成图标图片（PNG/JPG）！**
>    - AI 生成的图标是像素位图，有毛边底色、高清屏模糊，且**完全无法用 CSS `color` 动态改变颜色（如激活态变朱砂红）**，会产生严重的贴纸廉价感。
> 2. **所有人必须去 [阿里巴巴矢量图标库 (iconfont.cn)](https://www.iconfont.cn/) 搜寻最接近的图标！**
>    - **不需要一模一样，找最接近的即可**（例如设计稿里是古卷轴，在 iconfont 搜“卷轴”或“书卷”；设计稿是古琴，搜“琴”或“音乐”；设计稿是茶壶，搜“茶”或“执壶”）。
>    - 只要是单色/线性国风或扁平风格，视觉自然契合即可。
> 3. **项目已内置两个官方 iconfont CDN 库（在 `frontend/index.html`）：**
>    - 基础库：`https://at.alicdn.com/t/c/font_5104647_jepi4y0iy5.css`
>    - 国风定制库：`https://at.alicdn.com/t/c/font_5241957_dms3u40idy.css`
>    - 页面直接使用：`<i className="iconfont icon-xxx"></i>`，并在 Less 中指定 `font-size` 和 `color: @color-seal;`。
>    - 常见基础操作按钮（如返回、更多、折叠）也可搭配使用已安装的 `antd-mobile-icons`（如 `<RightOutline />`、`<DownOutline />`）。

### 2.2 成员 A（队友 1 / 全栈底座与物溯古今）详细分工与验收标准

#### 🛠️ 具体开发内容清单
1. **全局设计系统与工程底座维护**：
   - 维护 `frontend/src/context/ThemeContext.jsx`，提供 `theme`（`light` / `dark`）、`toggleTheme()` 与 `isDark` 状态；
   - 在 `frontend/src/styles/global.css` 中锁定宋代传统色 CSS 变量（`--gf-bg-paper`, `--gf-bg-card`, `--gf-seal`, `--gf-bamboo`, `--gf-gold`）。
2. **物溯古今 · 拍照识器前端（`Recognition.jsx`）**：
   - 维护图片采集器 `ImageCaptureAndProcess`，使用 `FileReader` 异步将用户拍摄或选取的图片转换为 Base64 编码；
   - 统一向后端 `/api/coze/recognition` 发起识物请求；
   - 接入 `RecognitionResult` 组件，渲染金石鉴赏、器物考释、文人品鉴心得三大卡片。
3. **后端大模型统一网关（`deepseekController.js`）**：
   - 维护白话雅译转译接口 `translateYayan`（`POST /api/deepseek/yayan`）；
   - 维护 AI 一键考释赋魂接口 `soulScholar`（`POST /api/deepseek/soul`）；
   - 维护多先贤人设对话接口 `deepseekChat`（`POST /api/deepseek/chat`）；
   - 严格落实**全接口离线优雅兜底机制**，断网或无 API Key 时秒级返回高质量古物与雅言考释数据。

#### 📋 严格验收标准 (Acceptance Criteria / DoD)
- [ ] **【功能验收 AC-A1】**：用户上传图片后，页面显示 Loading 动画，并在 2 秒内完成考证推演，正确输出「今物名称 ➔ 古代器物原型 ➔ 文人品鉴流变」。
- [ ] **【容灾验收 AC-A2】**：拔掉网线或清空 API Key 时，触发内置数据库兜底推演（如保温杯 ➔ 宋代执壶/汤瓶），页面绝对不抛红、不崩溃、不白屏。
- [ ] **【规范验收 AC-A3】**：代码中不得存在侵入其他成员页面的逻辑，所有网络请求统一通过 `axios.js` 统一拦截器。
- [ ] **【全栈验收 AC-A4】**：Node.js 控制器执行 `node -c` 语法检查 100% 通过无语法警告。

## 三、 五大核心业务功能技术规约

### 3.1 模块 1：物溯古今 · 拍照识器（今物寻古）
* **功能定位**：用户上传或拍摄现代日常生活物品（保温杯、雨伞、台灯、双肩包、奶茶等），AI 考证推演其古代对应器物原型、名称、用途与千年流变。
* **业务工作流**：
  1. 用户在前端触发拍摄/图片选取（`Recognition.jsx`）。
  2. 将图片转为 Base64 编码，调用 `/api/coze/recognition`。
  3. 后端若有大模型则调用多模态推演，若无或异常，则秒级返回高质量古物考证兜底。
  4. 前端展示：
     - **器物考释**：如「保温杯 ➔ 唐宋点茶所用之【执壶】与【汤瓶】」。
     - **文人品鉴心得**：流变考略（唐金银执壶 ➔ 宋影青汤瓶 ➔ 明紫砂提梁 ➔ 今不锈钢真空器）。
     - 支持语音播放或一键转发给 AI 知音展开讨论。
* **答辩严谨声明**：文档与答辩时明确说明：“本功能为国风趣味科普推演与文脉流变研习，非严谨考古鉴定工具”。

### 3.2 模块 2：雅集首页 · 白话雅译与岁时天象
* **功能定位**：作为产品门面，展现两宋文士雅集气象。
* **技术实现要点**：
  1. **日夜模式切换**：顶部右侧提供「晓色晨宣 ☀️ / 月下墨境 🌙」药丸切换按钮，驱动 `useTheme()` 切换全局 `data-theme` 属性。
  2. **白话雅译交互卷轴**：
     - 用户输入现代白话（如「今天下班好累，想去吃火锅喝奶茶」）；
     - 点击「转译雅言」调用 `/api/deepseek/yayan`；
     - 呈现典雅宋代风骨雅句（如「日暮倦归，思炙肉暖釜，兼啜酪饮以慰幽怀」）及风骨赏析；
     - 「摘录入卷」按钮：将雅言收藏到本地 `gufeng_yayan_list`。
  3. **古今时令与天象**：
     - 根据真实系统时间计算十二时辰（子丑寅卯辰巳午未申酉戌亥）；
     - 呈现干支物候（白露三候 · 菊有黄华 / 蟋蟀鸣秋）与诗词对仗。
  4. **今物寻古快捷对比卡片**：4 组现代器用与古物胶囊对照，直通识器页面。

### 3.3 模块 3：知音信札 · 先贤对话与迎请新友
* **功能定位**：打破冷冰冰的对话框，包装为古代文人尺素往还的「知音笔友」。
* **技术实现要点**：
  1. **水平知己画卷**：李白、苏轼、李清照、杜甫、辛弃疾、竹林雅集等头像，附带未读红点；
  2. **【迎请新友】抽屉（`InviteDrawer.jsx`）**：
     - 允许用户迎请任意历史名仕（陶渊明、纳兰性德、白居易等）；
     - **「✨ AI 一键考释赋魂」**：调用 `/api/deepseek/soul`，AI 自动考释生成生平纪略、朋友圈、文风标签与开场语；
     - 确认迎请后，存入本地 `gufeng_custom_sages`，即时在列表中生成专属知友。
  3. **【沉浸对话】（`ScholarChat.jsx`）**：
     - 顶部水墨立绘横幅（Hero Banner），展示李白等水墨形象与代表名句；
     - **4 大灵感快捷胶囊**：如「🍶 太白兄，何以解忧？」点击秒发；
     - 古风时辰时间戳（申时三刻等）；

### 3.4 模块 4：诗韵文府 · 诗词大卷轴与雅乐聆音
* **功能定位**：品鉴经典古诗词，实现“声画诗意”三位一体。
* **技术实现要点**：
  1. **宣纸大卷轴**：对仗断句、朝代与作者朱砂印章、白话赏析折叠面板；
  2. **雅乐聆音（听琴品韵）——【彻底解决版权痛点】**：

     - 按照中国传统五声音阶（宫、商、角、徵、羽：261.63Hz、293.66Hz、329.63Hz、392.00Hz、440.00Hz）模拟古琴泛音拨弦；
     - **零版权费用、零版权纠纷、无须外链音频、完全离线可用**；
  3. **一键摘录入卷**：点击盖下朱砂红印，持久化到「我的诗笺」。

### 3.5 模块 5：墨隐书斋 · 个人修持看板
* **功能定位**：用户研习成果沉淀殿堂。
* **技术实现要点**：

## 十、 弱网/断网离线应急预案 (Zero-Downtime Guarantee)

现场若遇 WiFi 拥堵、大模型 API 限流等突发故障，系统已内置 **三级容灾无感降级体系**：
1. **网络层**：Axios 统一拦截异常，任何 5xx 或超时直接捕获，绝不向 UI 抛出红色崩溃 Toast；
2. **AI 数据层**：服务端与前端均置入《广韵》《考工记》文博器物知识图谱，断网时秒级返回预置高保真数据；
3. **音频引擎**：Web Audio API 为浏览器端纯数学振荡计算，完全无需外网支持，断网依旧琴韵绕梁。
