## 🎯 一、 阶段背景与核心目标

经过前三阶段的猛攻，核心大底座（水墨粒子、平水韵算法、SSE 流式管道、飞花令状态机、识物大图上传）均已拔地而起。  
当前项目的核心痛点在于**各功能点之间的“闭环联动感”尚存断层**：
1. **文牒即生即逝**：对局结束生成的精美 Canvas 文牒退出后无处回看，书斋中仅有一个冷冰冰的数字积分；
2. **信札列表写死**：`LetterList` 里的会话与 `ScholarChat` 真实对答割裂；
3. **飞花令先贤席位受限**：目前仅李白与苏轼，且 49 句题库偏小；
4. **识物与先贤未能深度联动**：“引物溯古今”仍为写死文本。

本阶段刘霞主攻**「生态闭环与持久化资产沉淀」**，让用户在系统中的每一次修持、对弈、识物、对席都能转化为长期可视的文化数字资产。

## 🛠️ 二、 详细技术规格与开发要求

### 任务 1：书斋「翰林藏牒阁」与九品文阶功名系统
* **业务痛点**：通关文牒是本项目最具文化仪式感与分享价值的产物，目前用户在关闭对弈后无法在个人书斋二次查阅与下载。
* **开发要求**：
  1. **后端对局归档接口** (`backend/src/controllers/feihuaController.js` & 路由)：
     - 新增 `GET /api/deepseek/feihua/records`：支持分页查询当前用户已完成的对局记录（按时间倒序），包含胜负状态、令字、韵部、唱和对句与实得积分；
     - 提供单局文牒数据重构接口，保证文牒可随时重新渲染。
  2. **九品文阶晋阶算法** (`backend/src/utils/feihuaEngine.js` 与前端共享)：
     - 基于 `merit_points` 计算文人功名段位：
       - 0~5分：白衣布衣
       - 6~15分：秀才 / 茂才
       - 16~30分：举人 / 乡贡
       - 31~60分：贡士
       - 61~100分：同进士出身
       - 101~150分：进士及第
       - 151分以上：翰林大学士
  3. **前端「翰林藏牒阁」组件** (`frontend/src/pages/MinePage.jsx` 与相关组件)：
     - 在书斋页面新增「藏牒阁（通关诏书）」入口，点击展开宣纸折页展厅；
     - 列表中每一张已归档的对局均可点击查看，复用 `createScholarCertificate` 原生 Canvas 渲染 2x Retina 高清大图，并支持一键下载与系统分享。

### 任务 2：信札中枢（LetterList）动态打通与先贤飞鸽传书机制
* **业务痛点**：目前 `LetterList.jsx` 中信札最新对话为前端写死，与真实流式对话完全脱节。
* **开发要求**：
  1. **对话摘要与信札联动** (`frontend/src/pages/LetterList.jsx` / `ScholarChat.jsx`)：
     - 打通本地 Storage 与后端最新对席记录，信札列表中自动提取对应先贤的最新一句发言、对席时间（转化为古典时辰：子丑寅卯辰巳午未申酉戌亥）；
  2. **飞鸽传书（主动留柬）机制**：
     - 若用户与先贤对席超过 3 轮，离开页面后，先贤有概率（或固定触发）向雅士回赠一封「知音回柬」；
     - 信札列表对应先贤头像显示古典朱砂未读红点，点击进入展示先贤手书赠言（带宣纸信笺特效）。

### 任务 3：飞花令先贤席位扩充与题库跃迁
* **业务痛点**：目前飞花令仅开放李白、苏轼，题库 49 句极易出现名篇未收录提示。
* **开发要求**：
  1. **开放李清照、王阳明、杜甫**：
     - 李清照：偏好令字【花、愁、月、风】，词风婉约，优先出宋词名句；
     - 王阳明：偏好令字【山、水、心、明】，对答多含理趣与知行合一意境；
     - 杜甫：偏好令字【春、秋、江、风】，沉郁顿挫；
  2. **经典题库扩充至 150+ 句** (`backend/src/data/feihuaPoems.js`)：
     - 补充唐诗三百首与宋词精选中的高频对仗句，确保人教版教材与常见名篇覆盖率达到 85% 以上。

### 任务 4：携物入席（识物藏品 × 先贤对话流式考评联动）
* **业务痛点**：`ScholarChat.jsx` 中的“引物溯古今”为写死文本，识物模块与知音模块缺乏有生命力的串联。
* **开发要求**：
  1. 改造「引物溯古今」交互：
     - 点击后弹出「宝鉴藏品选择抽屉」，展示用户在识物模块曾经识别保存的器物（如古瓷、折扇、茶盏、佩玉）；
     - 选中一件藏品后，自动生成定制化求教发语（如：“太白兄，吾日前偶得一物，经物溯考证似宋代建盏，不知兄在唐时烹茶可曾用此等器具？”）；
     - 先贤通过 SSE 流式传输，基于历史背景与人设娓娓道来，形成识物到知音的沉浸式文化对谈闭环。
